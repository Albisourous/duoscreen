# duoscreen

Get the two-browser experience on your current iPhone, like iPhone Duo — an installable PWA with two web panes, a draggable liquid-glass divider, and per-pane address bars.

```bash
npm install
npm run dev
```

On iPhone: open the URL in Safari → Share → Add to Home Screen for fullscreen.

Some sites (Google, X, DuckDuckGo…) refuse iframe embedding via `X-Frame-Options`; use the ↗ button to open them in Safari instead.

See `AGENTS.md` for stack and agent-tooling notes.
